# schema دامنه‌دار کارتریج — BP-015 (v1.1 افزودنی)

> وضعیت: **DRAFT** — این الحاق بر پایهٔ سند قانون «تعریف آمادگی پایهٔ درسی» نوشته شده و
> ماتریس مرجع آن (`authoring/DOMAIN-MATRIX.json`) تا مُهر گام صفر معلم DRAFT می‌ماند.

## ۱) فیلدهای افزودنی سؤال (همگی اختیاری در v1.0 کارتریج — سازگاری پسین)

| فیلد | نوع | واژه‌نامه | نقش |
|---|---|---|---|
| `domainCode` | رشته | `D1..D8` (الگو: `^D[1-8]$`) | کد دامنهٔ قانونی؛ **بدون آن سؤال «میراثی» است و در پوشش دامنه شمرده نمی‌شود** |
| `qType` | رشته | فهرست نوع‌های دامنه در DOMAIN-MATRIX | نوع تمرین (عمق ماتریس) |
| `chapter` | رشته | `ف۱..ف۸` | فصل کتاب (برای ممیزی با نقشهٔ مادر) |
| `lesson` | رشته | شناسهٔ درس | هم‌ارز ساختاری `anchorId` — برای کارتریج‌های دامنه‌دار جدید |
| `answerFormat` | رشته | `عدد`، `کسر`، `گزینه‌ای`، `محور عددی`، `زوج‌سازی`، `شکل/نمودار` | قالب پاسخ (موتور ۶-قالبی — BP-016) |
| `renderHint` | رشته | آزاد | راهنمای رندر برای قالب‌های شکل/نمودار |

قاعدهٔ اعتبارسنجی موتور (cartridge-schema.js): این فیلدها **نرم** بازرسی می‌شوند —
مقدار نامعتبر = هشدار (زرد)، نه خطا (قرمز)؛ تا ۹۲ سؤال میراثی G2 بدون دامنه سبز بمانند.
از نخستین موج دامنه‌دار (v0.8+)، مبدل رسمی `domainCode` را برای سؤال‌های جدید الزامی می‌کند.

## ۲) ماتریس مرجع

- مسیر: `public/math-game/authoring/DOMAIN-MATRIX.json` — `khshab.domain-matrix/v1`
- G3: ۸ دامنه، حداقل‌های ۴۰/۴۸/۶۰/۱۰۰/۵۶/۴۸/۴۰/۶۰ = **۴۵۲**
- G2: ۶ دامنه، حداقل‌های ۲۴/۴۰/۵۰/۶۴/۴۰/۲۴ = **۲۴۲**

  و پس از مُهر معلم شمارش نوع‌به‌نوع هم قفل می‌شود.

## ۳) گزارش پوشش و گیت‌ها

```bash
# گزارش (خروجی Markdown + چاپ)
bun scripts/coverage-report.ts \
  --cartridge public/math-game/cartridges/KH-G2-MATH.json \
  --cartridge public/math-game/cartridges/KH-G3-MATH.json \
  --markdown reports/coverage-current.md

# گیت پوشش — fail-closed (ناکامل → exit 1)
bun scripts/coverage-report.ts --cartridge ... --gate

# گیت ضد-ادعا — هر نشانهٔ «پایه آماده» بدون پوشش کامل + مُهر معلم = قرمز
bash scripts/check-domain-claims.sh
bash scripts/check-domain-claims.sh --self-test   # ادعای کاذب → قرمز قطعی
```

قانون اعمال‌شده: «آماده» هرگز ادعا نمی‌شود، **اندازه‌گیری** می‌شود؛ اعلام «پایه آماده»
فقط در `v1.0` با ماتریس کامل مُهرشدهٔ معلم مجاز است (سند قانون §۵/§۸).
