# راهنمای جامع پکیج «کارگاه ضرب — نسخهٔ ۱۰»
**ایستگاه یادگیری و دستیار معلم ابتدایی بر پایهٔ سند «دستور ثابت ایستگاه»**

## ۱. معرفی و فلسفهٔ نسخهٔ ۱۰
نسخهٔ ۱۰ کارگاه ضرب، بازطراحی کامل لایهٔ تجربهٔ کاربری (UX) بر فراز موتور پایدار نسخهٔ ۹ است. این نسخه با تبعیت بی‌چون‌وچرا از سند **«دستور ثابت ایستگاه»**، تمامی زوائد حواس‌پرت‌کن (صندوقچه‌های شانس، جنگ و دشمن، پاداش‌های فریبنده، صداهای مهیب و صفحات تودرتو) را حذف کرده و یک محیط شناختی آرام، مفهومی و امن برای یادگیری ضرب در کلاس سوم دبستان فراهم آورده است.

### ارکان تغییرناپذیر مهندسی:
1. **حفظ و اتصال کامل موتور نسخهٔ ۹:** تمام لایه‌های زیرساختی شامل صف ذخیرهٔ آفلاین در `IndexedDB` (`local.mjs`)، ارتباط با سرور (`connectApi`)، احراز هویت `Firebase`، توکن‌های هویت، رسید پاسخ‌ها (`receipts`) و امکانات کامل نقش معلم روی سرور حفظ و به لایهٔ نسخهٔ ۱۰ متصل شده‌اند.
2. **نمره فقط از پاسخ پذیرفته:** رابط کاربری نمره نمی‌سازد؛ نمره مستقیماً از تأیید پاسخ درست استخراج می‌شود.
3. **تفکیک دو پوسته:** پوستهٔ کودک (ساده، خطی، نقشه به عنوان خانه) کاملاً مستقل از پوستهٔ معلم (مدیریت کلاس‌ها، ساخت کلاس، صدور پیوند دعوت ۲۴ ساعته، تأیید/لغو عضویت اعضا، مدیریت تابلوی نتایج و گزارش مرور) است.
4. **گرافیک ۱۰۰٪ برداری ایزومتریک (`SVG`) و فوق‌سبک:** تمامی ۸ دارایی بصری مجاز سند (بناهای سه‌گانه در سه وضعیت، مسیرهای ارتباطی، سلول‌های انرژی و پس‌زمینهٔ نقشه) به‌صورت گرافیک برداری چندلایه (`SVG`) پیاده‌سازی شده‌اند که بدون هیچ افت کیفیتی در هر بزرگ‌نمایی نمایش داده می‌شوند و حجم کل بسته را بیش از ۹۸٪ کاهش داده‌اند.

## ۳. راهنمای اجرا و استفاده

### الف) اجرای سریع و محلی (کلاینت):
1. در پوشهٔ پروژه یک وب‌سرور سبک لوکال اجرا کنید:
   ```bash
   python3 -m http.server 8080
   # یا:
   npx serve .
   ```
2. نشانی زیر را در مرورگر باز کنید:
   ```text
   http://localhost:8080/v10.html
   ```

### ب) اجرای آزمون‌های خودکار (Automated Tests):
```bash
npm test
# یا:
node --test tests/v10-station.test.js
```

### ج) اعمال گام‌به‌گام در مخزن گیت‌هاب (`bayrami1341/math-game`):
اسکریپت `apply-v10-to-github.sh` داخل بسته قرار داده شده تا تغییرات در ۴ کامیت منظم و گام‌به‌گام روی مخزن `https://github.com/bayrami1341/math-game` اعمال و Push شوند:
```bash
bash apply-v10-to-github.sh
```
