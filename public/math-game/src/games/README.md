# 🎮 بازی‌های ریاضی

هر پوشه یک بازی مستقل است. هر بازی شامل دو فایل است:

- **config.js** — تنظیمات بازی (بخش‌ها، ضریب‌ها، رنگ‌ها)
- **game.js** — منطق بازی

## بازی‌های موجود

| پوشه | توضیح |
|------|-------|
| `multiplication-1x1/` | ضرب یک‌رقمی در یک‌رقمی |

## افزودن بازی جدید

1. پوشه جدید بسازید: `src/games/<نام-بازی>/`
2. `config.js` را با بخش‌ها و تنظیمات بسازید.
3. `game.js` را با منطق بازی بنویسید.
4. در `index.html`، اسکریپت‌ها را با `defer` اضافه کنید.
