# راه سادهٔ آماده‌کردن میزبان سرور

Render میزبان اجرای سرور است؛ Firebase در این معماری محل داده و ورود است. حساب این دو جداست. فایل `render.yaml` فقط تنظیمات آماده است و با انتشار در GitHub، خودبه‌خود سرور ایجاد نمی‌کند.

## کاری که مالک حساب انجام می‌دهد

1. نشانی `https://dashboard.render.com/register` را در مرورگر باز کنید.
2. روش ثبت‌نام با GitHub را انتخاب کنید و خودتان شرایط حساب را بخوانید و تأیید کنید. رمز GitHub را فقط در صفحهٔ رسمی GitHub وارد کنید؛ آن را در گفتگو نفرستید.
3. اگر تأیید ایمیل خواست، در ایمیل خودتان تکمیل کنید.
4. اگر درخواست کارت یا پرداخت دیدید، متوقف شوید. برای این کار اجازهٔ فعال‌کردن پرداخت نداده‌اید.
5. پس از ورود به داشبورد، فقط اعلام کنید «حساب Render آماده است». نام کاربری، رمز، کد ورود و توکن لازم نیست.

ثبت‌نام به‌تنهایی سرور را به Firebase متصل نمی‌کند. انتخاب مخزن، بررسی پلن رایگان، دسترسی محدود به پروژه، هویت اجرایی امن و آزمون API مراحل بعد هستند. کلید مدیریتی Firebase هرگز نباید در فایل عمومی، GitHub یا متن گفتگو قرار بگیرد.

## وضعیت بستهٔ حاضر

فایل `render.yaml` برای یک سرویس آزمایشی رایگان با استقرار خودکار خاموش آماده شده است. اسرار باید فقط در مخزن اسرار میزبان تنظیم شوند. محدودیت خواب و بیدارشدن سرویس در رابط مدیریت می‌شود؛ مناسب‌بودن این پلن برای عرضهٔ نهایی و دسترسی حساب شما هنوز تأیید نشده است.

استقرار بدون حساب میزبان و هویت سرور تأییدشده کامل نمی‌شود. سرویس دائمی روی رایانهٔ شخصی یا تونل موقت به‌عنوان استقرار تولید معرفی نمی‌شود.
