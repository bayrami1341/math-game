# 🗺️ نقشهٔ فنی «کارگاه ضرب» — نسخهٔ رسمی که کارگاه‌بان با آن کار می‌کند

> این سند «حافظهٔ نقشه»ی کارگاه‌بان است. هر تغییر معماری باید همین‌جا به‌روز شود.

## ۱) چه چیزی می‌سازیم؟

**کارگاه ضرب** — سامانهٔ آموزشی ریاضی ابتدایی (نسخهٔ جاری: v10.3.0-beta):
- **موتور بازی**: `public/math-game/` (HTML/JS خالص، بدون فریم‌ورک، تست با `npm test` = ۸۱ آزمون)
- **داشبورد معلم**: Next.js 16 + shadcn/ui روی `/` (سرویس: پورت ۳۰۰۰، API در `src/app/api/`)
- **خط تولید محتوا**: خشاب‌های Excel («khshab-G*-MATH_v*.xlsx») ← **مبدل رسمی** (`tools/cartridge-converter/convert.mjs`) ← JSON کارتریج (`public/math-game/cartridges/KH-G*.json`)

## ۲) تقسیم کار (قرارداد مالکیت — بخش ۹)

| بازیگر | قلمرو | کانال |
|---|---|---|
| **Z.ai** | موتور، مبدل، سرور، استایل، کارتریج منتشرشده، CI، کارگاه‌بان | چت + مخزن (main/v10.3-beta) |
| **آرنا** | فقط `authoring/` و `download/` (خشاب، نقشهٔ صفحه، سند تحویل) | شاخه‌های `arena/**` |
| **معلم (مالک)** | رأی تربیتی نهایی روی محتوا | چت + مُهر |
| **کارگاه‌بان** | پایش + گیت ماشینی + PR + پیام‌رسانی | پورت 3030 + GitHub |

⛔ **مرز مطلق:** آرنا هرگز به `src/`، `tools/`، `cartridges/`، `server/`، `styles/`، `package*.json` و… دست نمی‌زند — گارد G0B.fail-closed.

## ۳) سرهای رسمی (SSOT محتوا)

`public/math-game/authoring/OFFICIAL-HEADS.json` — شش خانوادهٔ G1..G6 با version+sha256.
- هر موج جدید آرنا **فقط** از فایلِ اعلام‌شدهٔ این مانیفست شروع می‌شود؛ پایهٔ کهنه = `STALE_OFFICIAL_BASE_INCIDENT_07` = رد خودکار.
- پس از هر ادغام رسمی، Z.ai مانیفست را به‌روز می‌کند.

## ۴) گیت‌های ماشینی (fail-closed — نخستین شکست = توقف)

1. **G0 حق‌نشر**: هیچ PDF/تصویر کتاب/upload در گیت
2. **G0B مرز مالکیت**: صفر تغییر نرم‌افزاری از سمت محتوا
3. **OFFICIAL-HEADS**: خودسازگاری مانیفست
4. **تست موتور**: `npm test` (۸۱ آزمون) در `public/math-game`
5. **مبدل رسمی**: ۰ قرمز الزامی روی سرهای G2/G3 (self-baseline)
- اجرا: CI گیت‌هاب (`khshab-gate.yml` — روی هر push/PR به main/v10.3-beta/arena/**) + نمونهٔ محلی توسط کارگاه‌بان

## ۵) جریان یک تحویل (چرخهٔ کامل)

```
آرنا پوش به arena/XYZ
   ↓ (کارگاه‌بان: fetch هر ۱۰ دقیقه)
کارگاه‌بان: تشخیص هد جدید → worktree ایزوله
   ↓
گیت محلی: مقایسهٔ نسخه/SHA با OFFICIAL-HEADS + heads --verify + smoke مبدل
   ↓
ساخت PR خودکار به v10.3-beta + کامنت رأی فارسی برای آرنا
   ↓
🟢 هم‌گام/جدید → صف بازرسی دوم (Z.ai) → 🟡 → رأی معلم → ادغام رسمی + به‌روزرسانی مانیفست
🔴 پایهٔ کهنه → کامنت اصلاح برای آرنا (rebase) — بدون اتلاف وقت انسان‌ها
```

## ۷) توکن و امنیت

- توکن گیت‌هاب فقط داخل `git remote get-url origin` زندگی می‌کند — کارگاه‌بان آن را در زمان اجرا پارس می‌کند و **هرگز** لاگ/ذخیره نمی‌کند.
- فایل‌های حالت (`state.json`، `foreman.log`، `BRIEF.md`) در .gitignore هستند.
