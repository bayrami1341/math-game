# وضعیت و کارهای باقی‌ماندهٔ نسخهٔ ۹

تاریخ بررسی: ۱۷ اکتبر ۲۰۲۶. هدف نزدیک: آزمایش محدود معلم و همکاران روی دو دستگاه، با Firebase واقعی و بدون فعال‌سازی سرویس هزینه‌دار.

## نتیجهٔ بررسی

نسخهٔ ۹ نمونهٔ محلی قابل اجراست؛ نسخهٔ عمومی آمادهٔ استفاده نیست. نوشتن دوبارهٔ بازی، لیدربرد یا پنل معلم برای رفع مانع فعلی لازم نیست. انتشار فایل‌های رابط روی GitHub، سرور را فعال نمی‌کند.

بررسی فایل زندهٔ `v9-config.js` نیز نشان داد `apiBase` خالی است. فرمان جدید `npm run check:v9:release` این وضعیت را به‌درستی با `BLOCKED public-api` گزارش می‌کند؛ این خروجی، خطای آزمون نرم‌افزار نیست.

## بخش‌های پیاده‌سازی‌شده

| بخش | شواهد و محدودیت |
| --- | --- |
| ثبت نام در داستان و بازگشت به پرونده | پرونده‌های جدا برای کودکان هم‌نام، انتخاب کودک و چند کلاس؛ آزمون خودکار محلی |
| تمرین و مأموریت متحرک | تمرین مستقل از کلاس، پاسخ‌های منتظر ارسال، تأیید و محاسبهٔ نتیجه در سرور |
| ایستگاه و گنجینه | رکورد بهتر، حفظ نتیجهٔ قبلی، نشان‌ها و روشنایی از نتیجهٔ تأییدشده |
| لیدربرد نسخهٔ ۹ | بهترین مأموریت پایان‌یافته، مسیرهای جدا، رتبهٔ برابر، کنترل دسترسی و خاموش به‌صورت پیش‌فرض |
| پنل معلم فعلی | ساخت و بازیابی کلاس، دعوت، تأیید/لغو عضویت، گزارش فعالیت و کنترل تابلو |
| ذخیره‌سازی Firebase | آزمون قبلی با FirebaseStore واقعی موفق؛ هویت‌های آزمایشی محلی بودند، نه ورود واقعی Firebase Authentication |
| بستهٔ استقرار | Dockerfile، تنظیمات محیط و blueprint موجود؛ میزبان فعال و اعتبارنامهٔ اجرایی آن هنوز تأیید نشده‌اند |

اعتبارسنجی این تحویل: ۱۷ بررسی آموزشی و ۱۲۱ آزمون Node، جمعاً ۱۳۸ مورد موفق. این تعداد شامل آزمون‌های نسخهٔ ۸.۱ نیز هست؛ معادل ۱۳۸ آزمون پذیرش نسخهٔ ۹ روی دستگاه واقعی نیست.

## لازم برای تست محدود همکاران، به ترتیب اجرا

1. **یک API عمومی HTTPS:** میزبان قابل استفاده برای مالک، اجرای بستهٔ سرور و نگهداری خصوصی هویت اجرایی و کلید ثابت شناسه‌ها. فایل آمادهٔ استقرار جای حساب و سرویس فعال را نمی‌گیرد. هیچ سرویس پولی در این بررسی فعال نشده است.
2. **ورود واقعی و نقش معلم:** تأیید تنظیمات Authentication و دامنه، ورود کودک و معلم و فهرست مجاز معلمان. ورود Firebase CLI فقط ابزار مدیریتی است. در بررسی مدیریتی این نوبت، تازه‌سازی اعتبار CLI موفق نشد؛ این نتیجه برای اثبات انقضای ورود یا غیرفعال‌بودن Authentication کافی نیست.
3. **اتصال رابط منتشرشده:** پس از موفقیت آزمون سرور، درج نشانی در `v9-config.js` و انتشار. دعوت نسخهٔ ۹ یک پیوند/توکن صادرشده توسط سرور است؛ کد شش‌رقمی نسخهٔ ۸.۱ خودکار به دعوت نسخهٔ ۹ تبدیل نمی‌شود.
4. **آزمون پذیرش روی دو دستگاه:** معلم کلاس بسازد، دانش‌آموز از لینک دعوت بپیوندد، معلم تأیید کند، مأموریت کامل و نهایی شود، تابلو و گزارش معلم نتیجهٔ یکسان نشان دهند. سپس قطع و وصل اینترنت، بارگذاری مجدد و رد کاربر غیرعضو آزموده شود. بررسی بصری موبایل/دسکتاپ هنوز تأیید نشده است.

### محدودیت مهم مسیر فعلی ورود

رابط فعلی معلم از ارسال لینک ورود ایمیلی استفاده می‌کند. طبق مستندات رسمی Firebase در تاریخ بررسی، سهمیهٔ ارسال این لینک در Spark پنج ایمیل در روز است. این محدودیت باید پیش از دعوت گستردهٔ همکاران حل شود؛ راهکار پیشنهادی برای بررسی، افزودن ورود Google برای معلمان است، با حفظ تعیین نقش در سرور. تنظیم provider و آزمون عملی آن هنوز انجام نشده است؛ تغییر روش ورود صرفاً با نوشتن این گزارش اعمال نمی‌شود.

مرجع رسمی: https://firebase.google.com/docs/auth/limits#email_sending_limits

## لازم پیش از عرضهٔ نهایی

- بازیابی امن همان پروندهٔ کودک روی دستگاه دوم یا پس از خروج از حساب ناشناس؛ نام کودک به‌تنهایی مجوز مالکیت نیست.
- تعیین رفتار چند تب و انتقال نویسندهٔ جلسه؛ کنترل `writerEpoch` وجود دارد، اما مسیر کامل انتقال و بازیابی هنوز تکمیل نشده است.
- سیاست پشتیبان‌گیری، نگهداری و حذف داده و تصمیم مهاجرت ۸.۱. امتیازهای قدیمی نباید بدون کنترل به رکوردهای تأییدشدهٔ نسخهٔ ۹ تبدیل شوند.
- آزمون قوانین مستقیم Firebase، نقش‌ها، هویت اجرایی تولید و تنظیمات میزبان، همراه با ثبت نتیجهٔ پذیرش.

## قابل انجام پس از تست محدود اولیه

- صفحه‌بندی کامل اعضا و تاریخچه: پنل فعلی حداکثر ۱۰۰ عضو و ۲۰ فعالیت اخیر را نمایش می‌دهد و محدودیت را اعلام می‌کند.
- گزارش رشد چندجلسه‌ای، تکلیف شخصی و خروجی گزارش.
- بازکردن برنامه از حالت بسته بدون اینترنت؛ فعلاً صف پاسخ پس از بارگذاری کار می‌کند، پوستهٔ کامل آفلاین کش نمی‌شود.
- کنترل نرخ مشترک برای چند نمونهٔ سرور و تکمیل نظارت عملیاتی پیش از افزایش مقیاس.

این موارد نباید با عبارت کلی «فقط اتصال مانده» پنهان شوند؛ در عین حال، همهٔ امکانات تکمیلی شرط تست محدود چند همکار نیستند.

## فرمان آماده برای بررسی انتشار

```bash
npm run check:v9:release
```

پیش از تغییر تنظیمات رابط می‌توان میزبان را فقط با نشانی عمومی آزمایش کرد:

```bash
npm run check:v9:release -- --api https://YOUR-API-HOST
```

این فرمان فقط خواندن metadata، بررسی نبود حساب‌های توسعه، درخواست بدون توکن و preflight مبدأ GitHub Pages را اجرا می‌کند. کاربر، کلاس، جلسه یا رکورد ایجاد نمی‌کند. خروجی موفق این فرمان جای بررسی ورود واقعی، صحت داده یا دو دستگاه را نمی‌گیرد. خطای شبکه نیز نتیجهٔ عدم تأیید است؛ به‌تنهایی اثبات خاموش‌بودن میزبان نیست.

گزارش امکانات فعلی: [تحویل کلاس، لیدربرد و پنل معلم](V9-CLASSROOM-DELIVERY.fa.md).
