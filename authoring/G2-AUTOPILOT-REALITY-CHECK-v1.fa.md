## چه چیز باید واقعاً روشن شود تا عملکرد ربات دیده شود؟

1. **مسئول استقرار هسته (Z.ai):** یک runner/queue ماندگار با زمان‌بند، اعتبارنامهٔ کمینه، lease و checkpoint، retry محدود، heartbeat و داشبوردِ «آخرین اجرا/صف/گیت/دلیل توقف» مستقر کند. GitHub Action فقطِ push/PR چنین workerی نیست. جریان امنِ استقرار با PR متعارض حل شود، نه با تغییر شاخه یا خاموش‌کردن گیت.
2. **منبع امن:** C205 همان چاپ با SHA واقعی مورد انتظار `a93934b6c418d4c6efe5ebb109bbcfe4f5fb6024fa1f3b1b309a4ff6da2746de` صرفاً در vault خارج Git برای worker قابل خواندن باشد؛ خروجی رسانه/توکن در Git یا log عمومی نرود. نبود منبع باید روی داشبورد به‌عنوان `BLOCKED_SOURCE_UNAVAILABLE` دیده شود، نه وضعیت PASS.
3. **کارگر محتوا (خط آرنا/آشیل):** از صف ۱۰۸ صفحه و ماتریس وسعت/عمق همهٔ هشت فصل checkpoint بگیرد؛ کتاب→شاهد→مهارت→بازی/سؤالِ زرد→حسابرس مستقل→گیت موتور؛ رویدادهای ماشین‌خوان append-only و دلیل هر توقف ثبت شوند. در پایان پاسخ چت هیچ عاملِ استدلالی مستقلاً ادامه نمی‌دهد مگر runner واقعی کار جدید را آغاز کند.
4. **تست پیش از ادعای ۲۴ساعته:** چند اجرای بی‌چت، restart/crash و resume بدون شناسهٔ تکراری، source-SHA mismatch، توقف Wave 5، رد سبز بی‌شاهد، نبود credential، آزمون budget/heartbeat و عدم انتشار هنگام FAIL با شناسهٔ run و artifact ثابت تأیید شود. تنها پس از مشاهدهٔ چنین شواهدی نام «ربات فعال» به کار رود.
5. **مرز مالک:** تأیید کلی قبلی صرفاً مجوز کار فنی است. برای شما تأیید مرحله‌ای تازه لازم نیست؛ رأی آموزشیِ محدود و مجوز انتشار/زمان نهایی نزد صاحب اختیار باقی می‌ماند. من فقط پروندهٔ آماده برای تصمیم مالک می‌سازم، نه نسخهٔ «نهایی» به تصمیم خودم.

**اقدامِ قابل مشاهده در همین شاخه:** ابزار `authoring/tools/g2_supervisor_once.py` به‌عنوان **گزارشگر یک‌نوبتیِ خواندنی** ساخته و آزموده شد. snapshot ماشین‌خوانِ آخر در `authoring/g2-completion/G2-SUPERVISOR-STATE-v1.json` همهٔ گام‌های G0–G8، دلیل توقف منبع، و `runner_status=NOT_DEPLOYED_THIS_IS_ONE_SHOT_ONLY` را ثبت می‌کند؛ ۳ آزمونِ ردِ SHA ناسازگار، نبود منبع و دادهٔ جعل‌شده پاس شد. این ابزار **نه scheduler است، نه کارگر دائمی، نه انتشاردهندهٔ خشاب**؛ آن را به‌جای استقرار ربات به مالک معرفی نکنید.

**اولویت اجرایی کنونی:** ضمن آماده‌سازی محتوای زرد و ممیزی‌های مستقل، رفع دو پیش‌نیازِ منبع امن و استقرار runner/ادغام قراردادی باید در دست مسئول هسته باشد. زمان تکمیل یا فعالیت ۲۴ساعته تا عبور گیت‌های فوق قابل وعده دادن نیست.
