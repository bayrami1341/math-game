فاز صفر مبنای کد را ثبت کرده و فاز یک قرارداد `9.0.1-phase1` را قفل می‌کند. نسخهٔ بازی اصلی همچنان **۸.۱** است. [پیش‌نمایش رابط نسخهٔ ۹](v9.html) و [راهنمای اجرای سرور و رابط](docs/V9-RUNTIME-PREVIEW.fa.md) اضافه شده‌اند؛ اتصال تولید هنوز فعال و تأیید نشده است.

اجرای پیش‌نمایش محلی پس از نصب وابستگی‌ها:

```bash
npm run dev:v9
```

سپس `http://127.0.0.1:9090/v9.html` را باز کنید. روی GitHub Pages رابط منتشر می‌شود؛ API به میزبانی سرور جداگانه نیاز دارد.

برای اجرای سرور و آزمون‌ها، Node.js نسخهٔ ۲۲ یا جدیدتر و npm لازم است:

```bash
npm ci --ignore-scripts
npm test
```

اعتبارسنجی مستقل قرارداد با `npm run test:contracts` و آزمون سرور و صف با `npm run test:v9` اجرا می‌شود. اعتبارسنج‌ها در سرور استفاده می‌شوند و در صفحات بازی بارگذاری نمی‌شوند.
